# Purity tiers for arch-lint (crates/arch-lint).
# One `crate-name Tier` pair per line; Tier is `Pure`, `Core`, `Shell` or `Tooling`.
# `Core` crates depend only on Core crates and the allowlist in tools/reports/core-rules.toml.
# `Shell` marks an Impure crate. `Tooling` marks a build or lint crate outside the product.
# A crate has one line. Every crate under crates/ must be listed; an unlisted crate fails the gate.
# A module-tiered crate also has `crate::module Tier` lines, one per top-level module, where Tier is
# `Pure`, `StrictPure`, `Core` or `Shell`; its crate line then tiers the root files (lib.rs, main.rs,
# bin/). Every top-level module of such a crate must be listed, and a `Core` module may refer only to
# Core crates, the core-rules allowlist and other Core modules of its crate.
